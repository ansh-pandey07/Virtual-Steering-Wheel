# 🏎️ Virtual Steering Wheel

### ✋ Turn Your Hands Into a Virtual Steering Wheel

> **Control your computer with hand gestures and experience a new way of virtual driving!**

A computer vision-based project that uses **Python and OpenCV** to detect hand movements in real time and translate them into steering controls.

---

## 🌌 About The Project

**Virtual Steering Wheel** is an interactive computer vision project that transforms hand movements into virtual steering inputs.

Instead of using a physical steering wheel, users can interact with the system through hand gestures captured by a webcam.

The project combines real-time vision processing and gesture-based interaction to create an immersive virtual driving experience.

---

## ✨ Features

* ✋ **Hand Gesture Detection** — Detect hand movements using a camera.
* 🎥 **Real-Time Camera Tracking** — Capture live video input.
* 🏎️ **Virtual Steering Control** — Translate hand movements into steering inputs.
* 🐍 **Python Powered** — Built using Python.
* 👁️ **Computer Vision** — Uses OpenCV for visual processing.
* ⚡ **Interactive Experience** — Control the system through natural hand movements.

# 🚀 Getting Started

Follow these steps to set up and run the project on your computer.

## 📋 Prerequisites

Before starting, make sure you have:

* Python installed on your computer.
* A working webcam.
* Git installed.
* A code editor such as VS Code.

---

## 📥 Step 1 — Clone the Repository

Open your terminal or command prompt and run:

```bash
git clone https://github.com/ansh-pandey07/Virtual-Steering-Wheel.git
```

Navigate to the project folder:

```bash
cd Virtual-Steering-Wheel
```

---

## 🐍 Step 2 — Set Up a Virtual Environment

Create a virtual environment:

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

---

## 📦 Step 3 — Install Dependencies

Install the required packages:

```bash
pip install opencv-python
```

If the project includes a `requirements.txt` file, install all dependencies using:

```bash
pip install -r requirements.txt
```

---

## ▶️ Step 4 — Run the Project

Locate the main Python file in the project folder.

Run it using:

```bash
python main.py
```

> Replace `main.py` with the actual entry-point filename if it is different.

---

# 🎮 How To Use

### Step 1 — Launch the Application

Run the Python script to start the virtual steering wheel system.

### Step 2 — Allow Camera Access

Make sure your webcam is connected and accessible.

### Step 3 — Position Your Hands

Sit in front of the camera and position your hands within its field of view.

### Step 4 — Control the Steering

Move your hands to simulate steering movements. The system processes the camera feed and translates detected movements into steering inputs.

### Step 5 — Exit the Application

Use the exit control implemented in the application to close the camera window and stop the program.
